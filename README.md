🎵 Desktop Music Player (Estudo / Legado)

Nota: Este é um projeto antigo criado para fins de aprendizado e exploração inicial de tecnologias desktop e web. Ele se encontra em estado arquivado / pausado.

📌 Sobre o Projeto

A ideia principal deste projeto era desenvolver um aplicativo estilo Spotify (reprodutor de música), planejado inicialmente para rodar tanto em Desktop (PC) quanto em Dispositivos Móveis (Celular).

Este foi o meu primeiro projeto prático utilizando Electron, servindo como um laboratório de testes e aprendizado.

💡 Contexto e Aprendizados

Primeiros passos com Electron: Por ser o meu primeiro contato com a ferramenta, a estrutura de pastas e a arquitetura do projeto não seguem os padrões avançados de mercado atuais. Pode conter pequenos bugs ou decisões de código que hoje eu faria diferente.

Layout Responsivo / Mobile-First no Desktop: Na época, decidi criar a interface com proporções de tela de celular por achar mais confortável para iniciar o protótipo. A intenção era migrar o app posteriormente para mobile achando que a transição de um app Electron/React para celular seria simples.

React Native vs Electron: Na época do desenvolvimento, eu ainda não conhecia o React Native. Hoje compreendo que a abordagem ideal para o objetivo mobile teria sido utilizar o React Native desde o início.

Backend: O backend seria desenvolvido em Node.js, porém o projeto foi pausado justamente na etapa em que eu precisava construir essa integração, pois ainda estava aprendendo sobre desenvolvimento backend.

🛠️ Tecnologias Utilizadas

React — Interface do usuário (UI)

Electron — Encapsulamento para aplicação Desktop

Node.js — (Planejado para o Backend)
